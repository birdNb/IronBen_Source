## 1. 项目亮点
- **供电简单**：6S航模电池24V一次到位，DJI A板直降12V供8个总线舵机，再转5V供逻辑。
- **结构友好**：Z轴非承力，轴承+M5长螺丝定位；小腿过孔+尼龙扎带，长期运行不松动。
- **全开源**：3D文件、PCB、固件、上位机一键下载

## 7. 装机流程（10分钟上手）
1. **打印**：按STL默认方向，0.3mm，无支撑。
2. **电子预检**：
   - 空载测12V/5V/3.3V正常 → 再插舵机。
   - 舵机ID逐个烧写，顺序0-7（右前→左后）。
3. **机械**：
   - 先装轮子+轴承+M5×40，再装小腿→尼龙扎带抱紧。
   - 所有螺丝**对角预紧→3档最终拧紧**。
4. **通讯**：
   - LoRa四块同时上电，长按SET 3s绿灯快闪即同频。
   - CAN终端电阻DJI A板已带，扩展板**勿重复焊**。
5. **上电自检**：
   - 蜂鸣器"滴"→舵机蓝→绿灯→M3508微抖，完成。
